# hardware-embedded
(C++ / Arduino) : code embarqué, gestion des capteurs/actionneurs, pilotes de bus (I2C/SPI/UART).

## Contenu

- [`esp32cam/`](esp32cam/) : ESP32-CAM qui diffuse un flux vidéo MJPEG en Wi-Fi, avec scripts de flash (Windows, macOS, Linux)
- [`uno-q/`](uno-q/) : API capteurs sur Arduino UNO Q (FastAPI + sketch MCU), script d'installation et branchements
